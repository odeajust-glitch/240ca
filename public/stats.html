How this is counted

Visitors are counted with a one-way hash that is re-salted every day, so the same person on two different days cannot be linked. That makes the daily number accurate, but it means a multi-day visitor total would double-count anyone who returns — so only questions are totalled across days. No IP addresses and no question text are stored.
